# Visual Storytelling

## 1. Leitidee in drei Entscheidungen
1. **Leitmotiv:** ein wiederkehrendes Objekt/Symbol (z. B. Dollarnote, Pferd, Uhr, Haus). Es taucht in Variationen auf (roh → kostbar, klein → riesig).
2. **Farbwelt:** 2-3 Hauptfarben + 1 Akzent. Eine Farbe soll über das ganze Reel tragen.
3. **Bogen:** Setup (Problem/These) → Zuspitzung (Beweis/Übertreibung) → Wendung (Erkenntnis) → Auflösung (Handlungsimpuls/Ruhe). Bildästhetik folgt: Dunkel/eng → hell/weit.

## 2. Pro Szene
| Schritt | Frage |
|---|---|
| Kernaussage | Was ist die eine Behauptung dieses Satzes? |
| Emotion | Neugier, Unbehagen, Staunen, Ironie, Erleichterung, Gier, Nostalgie? |
| Bildidee | Eine **wörtliche** (Anker) + eine **metaphorische** (Spannung) |
| Rolle | Beweis, Kontrast, Übertreibung, Atempause, Pointe |

## 3. Metaphern-Methoden
- **Übertreibung:** ein Dollar → Zimmer voller Dollars.
- **Kontrast:** billig/roh vs. kostbar/klassisch (Kinderzeichnung vs. Altmeister).
- **Verfall/Zeit:** Sanduhr, rostige Uhr, verblasste Werbung, Ruinen, Eis schmilzt.
- **Maßstab:** winzige Figur vor riesigem Objekt, Sandburg vor Flut.
- **Verwandlung:** Geld, das sich auflöst/verbrennt/davonfliegt.
- **Kulturelle Referenz:** Filmszene, Gemälde, Wappen, Märchen.
- **Ersatzobjekt:** Brot/Eier/Benzinpreisschild statt "Preise"; Hamster im Rad statt "Hamsterrad".
- **Raum:** offene Landschaft = Freiheit, Labyrinth = Verwirrung, Käfig = Abhängigkeit, Villa = Ziel.

## 4. Verbot der Zufallsgalerie
Prüfe jeden Bildwechsel: *Warum jetzt, warum dieses Bild, was tut es mit dem Satz?* Wenn die Antwort fehlt, streichen.

## 5. Tempo
- Kurze Sätze → 1,5-2,5 s je Bild/Collage; lange Gedanken → 3-5 s mit Zoom.
- Pointe: Bildwechsel **kurz vor** dem Schlüsselwort (0,2-0,3 s), nicht danach.
- Atempausen: Alle 8-10 s ein ruhiges Vollbild.
- Hook (0-3 s): stärkstes, ungewöhnlichstes Bild, nicht das generischste.

## 6. Beispiel-Bogen "Inflation" (40 s)
Hook: Dollar-Note auf schwarzem Papier → Früher: Vintage-Supermarkt, 50er-Preisschilder → Heute: leeres Portemonnaie/Einkaufswagen-Stillleben → Mechanismus: Geld-Druckmaschine/Schmelzende Münzen → Folge: Sandburg-Flut/Sparschwein-Bruch → Wendung: Haus/Gold/Land als Wert → Auflösung: offene Landschaft, Sonnenaufgang.
