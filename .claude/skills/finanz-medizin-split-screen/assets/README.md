# assets
- `fonts/` – Manrope, Inter, Newsreader Italic (woff2, latin + latin-ext) aus dem Design-System der Website (OFL-Lizenz).
- `img/mark-finanz-medizin.png` – Markenzeichen (Badge auf der Trennlinie); `logo-finanz-medizin.png` – volles Logo (End-/CTA-Karte).
- `img/demo-image.jpg` – nur für `examples/D_szenenkatalog.json` (Open-Graph-Bild der Website).
Illustrationen (Arzt/Ärztin, Wohnung, Krankenhaus, Praxis, Ruhestandsort, Icons, Warnschild) sind **Vektor-Code in `templates/engine.js`** –
dadurch lassen sie sich parametrisch animieren (Alter, Pose, Stimmung) und bleiben konsistent.
